# Instructions for agents

This repository holds the FPSOT writing specification.

- The normative text is in `spec/en/` and `spec/fr/`. Every rule has an ID such as `WRT-001`.
- Follow `skill/SKILL.md` when you write or review text here. The spec text wins on any difference.
- Every page exists in English and in French, with the same file name and the same IDs.
- Terms and abbreviations come from `termbase/terms.yaml`. Add a missing term there first.
- Do not copy text from outside standards. Summarize them in your own words and cite the exact version.
- Commits follow Conventional Commits and are signed. Pull requests are squash-merged.
