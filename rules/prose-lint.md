# Prose checker rules

The FPSOT prose checker (`tools/prose-lint/ProseLint.java` in `fpsot-org/GitHub-Actions`) enforces these rules of this specification.

| Check | Rule |
|---|---|
| Sentence longer than 20 words | WRT-002 |
| Paragraph longer than 6 sentences | WRT-003 |
| Possible passive voice | WRT-004 |
| Noun made from a verb, followed by "of" | WRT-005 |
| Vague word or filler phrase from the list below | WRT-006 |
| Dash or semicolon joining two clauses | WRT-007 |
| Parenthesis in a sentence | WRT-008 |
| Five or more nouns in a row | WRT-001 |

## Vague words and filler phrases (WRT-006)

it should be noted, in order to, the fact that, a number of, note that, of course, as well as,
appropriate, appropriately, facilitate, facilitates, currently, basically, obviously, leverage,
leverages, perform, performs, utilize, utilizes, ensure, ensures, somewhat, clearly, various,
really, fairly, simply, quite, very, just, etc.
